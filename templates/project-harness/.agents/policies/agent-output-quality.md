# 에이전트 산출물 기준

에이전트는 작업 성격에 맞는 모드를 고르고, 결과물을 낸 뒤 아래 자기검사를 수행합니다. 모드는 품질 등급이 아니라 **자유도와 검증 강도**를 정하는 라벨입니다. 어떤 모드에서도 `AGENTS.md`의 Invariant가 먼저입니다.

| 모드 | 대상 | 자유도 |
| --- | --- | --- |
| Production | 기존 기능, 버그 수정, 정해진 레이어 안의 작업 | 낮음. 기존 구조와 용어를 따른다 |
| Foundation | 새 패키지, 공통 구조, 개발 도구 | 중간. 더 나은 구조를 제안할 수 있지만 이유와 대안을 남긴다 |
| Spike | 실험, 프로토타입, 기술 검증 | 높음. 단 프로덕션 코드와 격리한다 |

Spike에서 만든 것을 제품에 넣을 때는 Production 기준으로 다시 정리합니다.

## 자기검사 (권고)

- [ ] 요청하지 않은 기능, 추상화, 설정을 넣지 않았는가
- [ ] 변경된 모든 줄이 요청과 연결되는가
- [ ] 기존 구조, 네이밍, 도메인 용어를 따랐는가
- [ ] 검증 명령을 실제로 돌렸고 결과를 보고했는가
- [ ] 확신이 없는 부분을 확신 있게 쓰지 않았는가 (추정이면 추정이라고 적는다)

미충족 항목이 남으면 체크리스트 결과로 사용자에게 공유합니다.
